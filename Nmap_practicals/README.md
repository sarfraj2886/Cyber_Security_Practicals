# Namp Practical -- Host Discovery
# Objective -- to scan the network and identify active live host without performing a full port scan.
# Command used -- nmap -sn 192.168.120.0/24
# -sn -- Mean scan no port.
# Key observation -- Successfully discovered active device along with IP address and MAC address.
