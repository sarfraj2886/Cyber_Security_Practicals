# Cyber_Security_Practicals Portfolio


Welcome to my Cyber Security portfolio repository. This project serves as a comprehensive log of my practical hands-on experience with industry-standard penetration testing and network auditing tools. 

The primary objective is to demonstrate my tactical and technical knowledge in network scanning, packet analysis, web application security, and vulnerability exploitation to prospective interviewers and security professionals.

---

##  Repository Structure & Core Modules

This repository is organized into four distinct modules, each focusing on a critical phase of ethical hacking and security auditing:

## 1. [Nmap Practicals](./Nmap_practicals/)
* **Focus:** Network Reconnaissance, Active Host Discovery, and Port Scanning.
* **Key Tasks:** Executing TCP Connect/SYN/UDP scans, Service Version Detection, Operating System Fingerprinting, and Timing Template optimization.

## 2. [Wireshark Practicals](./Wireshark_practicals/)
* **Focus:** Deep Packet Inspection (DPI) and Live Network Traffic Monitoring.
* **Key Tasks:** Capture filter configurations, display filter operations, protocol header inspection (Ethernet, IPv4, IPv6, TCP, UDP, ICMP, DNS, ARP), and unencrypted credential harvesting.

## 3. [Burp Suite Practicals](./Burpsuite_practicals/Module/)
* **Focus:** Web Application Penetration Testing and Traffic Interception.
* **Key Tasks:** Intercepting HTTP/HTTPS requests via Burp Proxy, manipulating parameters using Repeater, and configuring automated dictionary/brute-force attacks via Intruder.

## 4. [Metasploit Framework](./Metasploit_Framework/)
* **Focus:** Vulnerability Exploitation, Payload Generation, and Post-Exploitation.
* **Key Tasks:** Generating custom reverse shell binaries via MSFvenom, setting up generic Multi-Handlers, and managing remote Meterpreter sessions to gather system intelligence.
